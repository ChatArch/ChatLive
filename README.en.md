# ChatLive

ChatLive is the ChatArch live tooling package entrypoint. The package currently keeps a minimal root-only CLI so the live tooling shell remains installable, discoverable, and releasable; real live subcommands are not exposed yet.

## Quick Start

```bash
pip install ChatLive
chatlive --help
chatlive --version
chatlive --tree
chatlive --tree-brief
```

## Current CLI Tree

The following is the registered surface from `chatlive --tree-brief`. `chatlive --tree` normally includes parameter signatures; this root-only CLI has no business-command parameters, so the two views are identical.

```text
chatlive
├── --help  # Show this message and exit.
├── --version  # Show the version and exit.
├── --tree  # Print the registered CLI tree and exit.
└── --tree-brief  # Print the registered CLI tree without parameter signatures and exit.
```

## CLI Boundary

- The current CLI only exposes root options and has no business subcommands.
- `--tree` and `--tree-brief` are generated by ChatStyle from the real Click command registration and are used to align README, docs, and tests.
- When real live tooling commands are added later, update the Click registration first and then sync docs from the real `chatlive --tree` and `chatlive --tree-brief` output.

## Layout

- `src/`: package source code
- `tests/code-tests/`: code tests and migrated historical tests
- `tests/cli-tests/`: real CLI tests, doc-first
- `tests/mock-cli-tests/`: mock/fake CLI tests, doc-first
- `docs/`: long-lived project docs built by MkDocs
